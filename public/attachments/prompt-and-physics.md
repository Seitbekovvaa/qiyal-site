# Video Prompt Structures & Motion Physics

## High-End Prompt Anatomy (Seedance / Kling / Veo level)

Recommended structure:

[Character / Identity Lock] + [Precise Action + Physics] + [Camera + Lens] + [Environment + Lighting] + [Style] + [Timing / Beats] + [Constraints]

Example pattern for a single shot:
"A [detailed character], [precise biomechanical action with weight and secondary motion], [camera movement and lens], [lighting and atmosphere], [style], [constraints: preserve identity, natural physics, hard cut only]"

For multi-shot use explicit time codes or clear shot separation:
[0-3s]: ... 
[3-6s]: hard cut to ...

## Physics Language That Works

Always make weight and contact explicit:
- "plants the left foot firmly, weight shifts, hips rotate, right leg drives forward with natural follow-through"
- "body has real mass and momentum"
- "hair and cloth continue moving after the main action stops"
- "impact absorption in the knees and ankles"
- "no floating, no foot sliding, ground contact is solid"

For fast action (run / jump / fight):
- Isolate one primary action per generation when possible
- Anchor speed with stationary environmental elements
- Describe acceleration curve and recovery
- Specify secondary motion separately from primary action

## Camera Language

Use precise film terms:
- locked-off / static
- slow dolly-in / push-in
- tracking shot / side tracking
- orbit / arc
- crane / boom
- handheld with subtle operator breathing / urgent tracking

One dominant camera intention per shot is preferred.

## Transitions

Default to cinematic hard cuts and clear angle changes.
Avoid morph, dissolve, or mix transitions unless the user specifically requests a stylistic exception.
