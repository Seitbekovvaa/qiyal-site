# Tools & Best Practices for Creating Storyboards (Раскадровки)

## Professional Tools Landscape (2025–2026)

### Industry Standard / High-End
- **Toon Boom Storyboard Pro** — The professional ceiling for animation and episodic work. Full drawing tools, camera moves, timing, audio, animatic export, direct pipeline into Harmony. Steep learning curve, expensive, worth it for serious production.
- **FrameForge / Previs tools** — Strong for accurate camera lens simulation and 3D blocking.
- **ShotPro** — Accessible 3D previs and camera blocking (iOS-focused historically).

### Dedicated Storyboard / Agency Tools
- **Boords** — Clean panels, versioning, client comments, animatics. Popular with commercials and agencies. Has AI frame assist.
- **StudioBinder** — Full pre-production suite (storyboards + shot lists + schedules + call sheets). Best when the whole production lives in one system.
- **Celtx** — Script + storyboard integration.

### Free & Lightweight
- **Storyboarder (Wonder Unit)** — Free, open-source, excellent for hand-drawn boards. Simple, fast, exports well. Best starting point if you can draw.
- **Milanote / Miro / FigJam** — Infinite canvas for moodboards + rough boards + collaboration.
- **Procreate / Photoshop / Clip Studio** — Flexible drawing tools many artists still prefer for custom boards.

### AI-Assisted Storyboarding (2026)
- Tools such as Storyflow, Katalist, LTX Studio, Elser AI, Atlabs and similar platforms that generate panels from script while attempting character consistency.
- Strength: speed of first pass and script-to-board conversion.
- Weakness: character consistency and precise camera language still require strong human direction and reference locks.
- Best used as a rapid draft layer that is then refined by a director or storyboard artist.

## Essential Best Practices

1. **Aspect Ratio First**
   - Choose and lock the ratio early: 16:9, 2.39:1 (anamorphic), 1.85:1, 9:16 (vertical), etc.
   - All panels must respect the final framing.

2. **Panel Content**
   Every panel should communicate:
   - Shot size (WS, MS, CU, ECU…)
   - Camera angle (eye-level, high, low, Dutch…)
   - Camera movement (static, pan, tilt, dolly, tracking, crane, handheld) — shown with arrows
   - Subject action and important staging
   - Dialogue / key sound / music cues
   - Approximate duration / timing

3. **Arrows & Notation**
   - Subject movement arrows inside the panel
   - Camera movement arrows (growing arrow = push-in, arrow to edge = pan following, etc.)
   - Clear labels: “DOLLY IN”, “TRACK LEFT”, “HARD CUT TO”, “MATCH CUT”

4. **Continuity Rules**
   - Screen direction and eyelines must be consistent unless intentionally broken.
   - Character scale and position relative to previous shot should feel continuous.
   - Use matching action or clear geographic anchors when cutting.

5. **From Thumbnail → Animatic**
   - Start with rough thumbnails for rhythm and coverage.
   - Refine key panels for clarity of staging and emotion.
   - Add timing and export an animatic (even rough) to test pacing before full production or AI generation.

## Integration with AI Video Generation

- A well-made storyboard is the best prompt source for multi-shot AI video.
- Translate each panel into a structured prompt: shot size + action + camera + physics + style + identity lock.
- Use the storyboard as the shot list and continuity bible.
- For character consistency: extract a hero frame or detailed description from the board and lock it across generations.
- Prefer hard cuts that match the storyboard’s intended transitions.
